# My Finances — Legal and Information Pages

Public information pages for **My Finances**, a personal, non-commercial Windows desktop finance tracker that uses Enable Banking to connect the account owner's BOV and Revolut accounts.

- [Privacy Policy](privacy.html)
- [Terms of Use](terms.html)

Only static website files belong in this repository. **Do not upload** your banking private keys, API credentials, session tokens, transaction data, SQLite databases, backups, or the My Finances application itself.

## Publishing with GitHub Pages

1. Change the repository visibility to **Public** if it is currently private.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, then **main** and **/(root)**; save.
4. After deployment, confirm the URLs work:

   - https://qauntumtuneller.github.io/My-Finances-Policies/privacy.html
   - https://qauntumtuneller.github.io/My-Finances-Policies/terms.html

Both policies describe the private, local-first application as currently understood. Review and update them if the application's data handling changes.
